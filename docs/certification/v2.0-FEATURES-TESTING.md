# TMS v2.0 Feature Flags & Configuration Testing Strategy

## 1. Feature Flag Precedence
- [ ] **Global Default**: Verify feature is disabled globally by default.
- [ ] **Rollout Percentage**: Test that with 50% rollout, approximately half of a sample user set sees the feature (requires mock user context in tests).
- [ ] **Organization Override**: Verify that an organization-specific override (e.g., ENABLED) takes precedence over the global state (e.g., DISABLED).
- [ ] **Subscription Plan**: Verify features scoped to specific plans (e.g., "ENTERPRISE") are correctly resolved.

## 2. Configuration Management
- [ ] **Persistence**: Update a configuration value and verify it persists in the database.
- [ ] **JSON Validation**: Attempt to save invalid JSON and ensure the UI/Action prevents it.
- [ ] **Sensitive Values**: Verify that values marked as `isSensitive` are handled with extra care in audit logs (masked if necessary, though current audit logs store full newData).

## 3. Rollback & Versioning
- [ ] **Version Creation**: Verify that updating a feature flag creates a new `FeatureFlagVersion` entry.
- [ ] **Rollback**: Simulate a rollback by applying data from a previous version and verify the state is restored.

## 4. Audit Trail
- [ ] **Change Attribution**: Verify that `lastModifiedById` is correctly set to the current Super Admin.
- [ ] **Audit Accuracy**: Check `AuditLog` for `FEATURE_FLAG_UPDATED` and `CONFIGURATION_UPDATED` entries, ensuring `oldData` and `newData` are correctly captured.

## 5. Performance
- [ ] **Cache Performance**: Since feature flags are checked frequently, evaluate the need for a Redis-based cache (Upstash) in the service layer if database latency becomes a bottleneck.
- [ ] **Scale**: Verify dashboard stats remain accurate with hundreds of flags and thousands of overrides.

## 6. UI/UX
- [ ] **Responsiveness**: Test the Feature List and Config Editor on mobile devices.
- [ ] **Loading States**: Verify skeletons or loading indicators appear during transitions.
- [ ] **Error Handling**: Verify toast notifications appear on failed saves or unauthorized attempts.
