# TMS v2.1 Enterprise Reporting & Owner Statements Certification

## 1. Financial Accuracy
- [ ] **Decimal Precision**: Verify all calculations use `Prisma.Decimal` and avoid JS floating point errors.
- [ ] **Income Statement**: Cross-verify total income against `Payment` table for specific date ranges.
- [ ] **Owner Statements**: Verify `revenue - expenses = netPayout` consistently across 100+ generated statements.

## 2. Multi-Tenant Isolation
- [ ] **Data Boundaries**: Ensure `ReportRepository` always uses `getTenantDb(organizationId)` for non-platform reports.
- [ ] **Cross-Tenant Leakage**: Test generating a report with a valid `templateId` but from a different `organizationId`.

## 3. Asynchronous Processing (QStash)
- [ ] **Export Engine**: Verify large exports (10k+ rows) are queued and processed without blocking the main thread.
- [ ] **Timeout Handling**: Ensure the `ReportExecutionService` can handle long-running data gathering.

## 4. Scheduling & Idempotency
- [ ] **Frequency Accuracy**: Test Daily, Weekly, and Monthly schedules.
- [ ] **Duplicate Prevention**: Ensure a scheduled report only runs once per period even if the trigger is retried.

## 5. Exports (PDF/Excel)
- [ ] **PDF Rendering**: Verify formatting, company branding, and pagination on Owner Statements.
- [ ] **Excel Integrity**: Verify that Excel exports maintain data types (numbers as numbers, dates as dates).

## 6. Audit Logging
- [ ] **Action Tracking**: Verify `REPORT_GENERATED`, `OWNER_STATEMENT_GENERATED`, and `REPORT_EXPORTED` are logged with full filter metadata.
- [ ] **IP Attribution**: Ensure actor IP and timestamp are captured for all exports.

## 7. Performance at Scale
- [ ] **Rent Roll**: Test performance on property with 1,000+ units.
- [ ] **Platform Revenue**: Verify Super Admin reports execute efficiently across thousands of organizations.
